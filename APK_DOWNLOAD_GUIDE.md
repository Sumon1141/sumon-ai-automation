# 📱 Sumon AI APK - Direct Download & Install

## 🎯 What is Sumon AI?

Sumon AI is a **Voice-Controlled AI Automation Agent** for Android that:
- ✨ Recognizes voice commands in Bengali & English
- 🤖 Uses multiple AI models (Gemini, Claude, OpenAI, Groq)
- 📱 Automates WhatsApp, Facebook, Telegram
- 🌐 Searches the web and gets weather
- ⚡ Controls Wi-Fi, Bluetooth, volume, and more
- 🔐 Keeps all your API keys encrypted and safe

## ⚡ Super Quick Start (3 minutes)

### 1️⃣ Download APK
Go to GitHub Releases and download `app-debug.apk`:
```
https://github.com/Sumon1141/sumon-ai-automation/releases
```

### 2️⃣ Install on Phone
1. Open file manager
2. Tap the APK file
3. Tap "Install"
4. Done! ✓

### 3️⃣ Open & Use
1. Find "🤖 Sumon AI" on home screen
2. Tap to open
3. Enable Accessibility (Settings → Accessibility → Services → Sumon AI → ON)
4. Start giving voice commands! 🎤

## ❓ FAQ

**Q: Can I use this without Internet?**  
A: No, API calls require internet. But you can use voice commands offline if you configure local models.

**Q: Is my data secure?**  
A: Yes! API keys are encrypted with AES-256. No data is stored on Sumon servers.

**Q: Which Android version?**  
A: Android 8.0 (API level 26) and above.

**Q: How do I get API keys?**  
A: Visit the website links above. Most offer free tiers for testing.

**Q: Can it work with other apps?**  
A: Yes! With Accessibility Service enabled, it can control WhatsApp, Facebook, Telegram, and more.

## 🐛 Troubleshooting

| Issue | Solution |
|-------|----------|
| APK won't install | Settings → Security → Unknown Sources → Enable |
| Accessibility not working | Disable and re-enable in Accessibility Services |
| Voice not recognized | Check microphone permission and try again |
| API key error | Copy key carefully (no extra spaces) |
| App crashes | Clear app cache: Settings → Apps → Sumon AI → Storage → Clear |

## 🚀 Build From Source (Optional)

If you want to build yourself:

```bash
# Clone repository
git clone https://github.com/Sumon1141/sumon-ai-automation.git
cd sumon-ai-automation

# Build APK
./gradlew assembleDebug

# Install on device
adb install app/build/outputs/apk/debug/app-debug.apk
```

### Windows Users:
```bash
gradlew.bat assembleDebug
adb install app\build\outputs\apk\debug\app-debug.apk
```
