# 🚀 How to Get Started with Sumon AI - 3 Minutes

## ⚡ Super Quick Installation

### Step 1: Download APK (30 seconds)
- Go to: https://github.com/Sumon1141/sumon-ai-automation/releases
- Download `app-debug.apk` to your phone

### Step 2: Install (1 minute)
1. Open file manager on your phone
2. Tap the APK file
3. Tap "Install"
4. Wait 2-3 seconds

### Step 3: Open App (30 seconds)
1. Find "🤖 Sumon AI" on home screen
2. Tap to open
3. Done! ✓

---

## 🔧 Initial Setup (5 minutes)

### Enable Accessibility (Required)
```
Settings → Accessibility → Services → Sumon AI → Turn ON
```

### Add API Keys (Optional but Recommended)
Tap "🔑 API Key Manager" and add any of these FREE APIs:

- **Gemini API** (Google) - FREE tier
- **Claude API** (Anthropic) - $5 free credit
- **OpenAI API** - $5 free credit  
- **Groq API** - FREE unlimited
- **ElevenLabs** - 10k free characters
- **Tavily Search** - 1k free searches

### Test Voice Commands
Tap "🎤 Start Voice Command" and say:
- "What's the weather?"
- "Send WhatsApp message to John: Hello"
- "Search for restaurants near me"

## 🆘 Troubleshooting

**Can't install APK?**
→ Go to Settings → Security → Unknown Sources → ON

**Accessibility not working?**
→ Settings → Accessibility → Services → Find Sumon AI → Enable

**Microphone not working?**
→ Settings → Permissions → Microphone → Allow

**API Key error?**
→ Copy the key again (no spaces) and try again
